# Models

Every trading model lives in `models/<family>/NN-slug/` where `<family>` is one
of `classical`, `ml`, `microstructure`, `alt-data`.

## Per-model conventions

```
NN-slug/
├── README.md          # Hypothesis, data used, results summary, takeaways
├── model.md           # YAML frontmatter — machine-readable metadata
├── notebook.ipynb     # The narrative: EDA → features → backtest → analysis
├── backtest.py        # Reproducible entry point (uses tradinglib.backtest)
├── train.py           # Reproducible training (ML / DL models only)
└── results/
    ├── metrics.json
    └── equity_curve.png
```

## `model.md` frontmatter

The frontmatter is the spine of the cross-axis index — `MODELS.md` at the
repo root is auto-generated by scanning every `model.md`.

```yaml
---
name: Bollinger Mean Reversion
family: classical            # classical | ml | microstructure | alt-data
window: intraday             # tick | intraday | swing | long-term
assets: [equities]           # equities | crypto
data_sources: [yfinance_daily_bars]
status: complete             # exploratory | working | complete
sharpe_oos: 1.2
max_drawdown: -0.15
---
```

After adding or updating a model, regenerate the index:

```bash
uv run python scripts/regenerate_models_index.py
```

CI fails if `MODELS.md` is stale on the main branch.

## Numbering

Models are numbered per family (`01-`, `02-`, …) in the order they were
created. Numbering is for chronological browsing only and carries no other
meaning.
