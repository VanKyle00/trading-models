Overview

This is the reading room for the trading-models repository. The work is split into two tracks, kept separate on purpose. The model breakdowns are end-to-end empirical papers — one per model, each carrying a hypothesis through a lookahead-safe backtest to a verdict, winners and negative results reported alike. The concept writeups are the theory those models rest on, derived from first principles before any backtest, so that the empirical results are read with the mechanism already in hand.

Pick a track below. Shared evaluation conventions live in methodology.md; shared definitions in the glossary.

Model Breakdowns

One self-contained working paper per model — the data, the signal, the backtest, and the result, on a common evaluation protocol so families compare on the same footing. Includes the deliberate negative results.
